# Subagent Gang & Contributor Collective — `unsigned-gg/lsc`

This directory defines the automated subagent personas and the contributor roster for the
`ls` (LeanSpec Parser & AST Engine) repository.

## Subagent Roles

- **`ls-foreman`**: Orchestrates critical path work, plans builder/critic waves, and verifies landing gates.
- **`ls-builder`**: Bounded builder. Fabricates AST parsers, frontmatter schema validators, and rule engines.
- **`ls-critic`**: Adversarial reviewer. Audits diffs for parser backtracking, memory leaks, and unsafe code.
- **`ls-engineer`**: General systems engineer for researching grammar, AST models, and terminal formatting.
